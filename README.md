# lossePerso

## Local Business Finder

Application locale gratuite de recherche d’entreprises avec OpenStreetMap, carte Leaflet, favoris IndexedDB et exports CSV/JSON.

- **Application :** [`LOCAL-BUSINESS-FINDER/`](LOCAL-BUSINESS-FINDER/)
- **Démarrage Windows :** extraire le dossier complet puis double-cliquer sur `start.bat`.
- **Guide :** [README de l’application](LOCAL-BUSINESS-FINDER/README.md) · [Installation](LOCAL-BUSINESS-FINDER/docs/INSTALLATION.md) · [Guide utilisateur](LOCAL-BUSINESS-FINDER/docs/USER-GUIDE.md)
- **Vérifications :** [Rapport de tests](LOCAL-BUSINESS-FINDER/docs/TEST-REPORT.md)

Aucun compte ni aucune clé API payante. Internet est nécessaire pour les recherches et le fond de carte ; les fiches enregistrées restent consultables hors connexion.
